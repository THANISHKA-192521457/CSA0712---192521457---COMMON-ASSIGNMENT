Network Security and Firewall Monitoring System (CSA0712)

Requirements: Python 3.8 or above. No extra libraries are needed.

How to run:
1. Extract the ZIP folder.
2. Open a terminal inside the extracted folder.
3. Type:  python firewall_monitor.py
4. Open sample_output/dashboard.html in a web browser to see the dashboard.

Files:
- CSA0712_Network_Security_Firewall_Report.docx : full report
- firewall_monitor.py : source code
- rules.json : firewall rules (edit to add or remove rules)
- sample_output/ : security log, alerts and dashboard created by the program
- images/ : diagrams used in the report
